# Face Detection App 😀

A real-time **face detection** application built with **Python** and **OpenCV**.

## ✨ Features
- Detect faces in images and live camera feeds
- Haar Cascade classifier (fast, CPU-friendly)
- Simple, clean usage API

## 🚀 Getting Started
```bash
pip install -r requirements.txt
python app.py
```

## 🛠️ Built With
- Python · OpenCV · Haar Cascades
